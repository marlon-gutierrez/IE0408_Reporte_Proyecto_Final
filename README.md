# Analog PID Controller for a Sallen-Key Filter

Analog control system designed and experimentally implemented as part of the **IE0408 – Electronics Laboratory II** course at the **University of Costa Rica (UCR)**.

The project consisted of modeling a second-order Sallen-Key low-pass filter, designing a PID controller based on the experimentally identified plant, implementing the controller using analog operational-amplifier circuits, and validating the complete closed-loop system through laboratory measurements.

## Overview

The main objective of the project was to design and implement an **analog PID controller** capable of controlling the response of a second-order Sallen-Key filter.

The complete development process included:

* Physical implementation of the Sallen-Key plant.
* Experimental acquisition of the plant step response.
* System identification using MATLAB.
* PID controller design and tuning.
* Analog implementation of the proportional, integral, and derivative stages.
* Closed-loop hardware integration.
* Experimental validation using laboratory instrumentation.
* Evaluation of reference tracking and disturbance rejection.

## System Architecture

The closed-loop system is composed of:

**Reference → Error Amplifier → Analog PID Controller → Sallen-Key Plant → Feedback**

The error signal is generated by subtracting the measured plant output from the reference signal.

The PID controller was implemented using a parallel architecture:

$$
C(s)=K_p+\frac{K_i}{s}+K_d s
$$

Each control action was implemented using operational-amplifier circuits, and their outputs were combined using an analog summing stage.

## Plant

The controlled plant is a **second-order Sallen-Key low-pass filter** implemented using an LF353 operational amplifier.

The physical circuit was excited using a step input, while its input and output signals were measured with an oscilloscope.

The experimental data were processed in MATLAB and used with the **System Identification Toolbox** to obtain a second-order model with a time delay.

The identified plant model achieved a **98.3% fit** with the experimental response:

$$
G(s)=
\frac{274.74}
{s^2+4.61s+118.86}
e^{-0.00015s}
$$

An analytical model of the Sallen-Key circuit was also obtained and used as an additional reference for comparison.

## PID Controller Design

The experimentally identified model was used in MATLAB to design the PID controller.

The final controller parameters were:

| Parameter |   Value |
| --------- | ------: |
| \(K_p\)   |  4.8781 |
| \(K_i\)   | 21.7534 |
| \(K_d\)   |   0.273 |

The corresponding integral and derivative time constants were:

$$
T_i = \frac{K_p}{K_i}=0.224\,s
$$

$$
T_d = \frac{K_d}{K_p}=0.056\,s
$$

These parameters were converted into resistor and capacitor values for the physical analog implementation.

## Hardware Implementation

The complete controller was implemented using **LF353 operational amplifiers** and passive RC networks.

The analog system included:

* Error subtraction stage
* Proportional stage
* Integral stage
* Derivative stage
* Analog summing stage
* Sallen-Key plant
* Feedback loop

The circuit was assembled and experimentally tested using laboratory instrumentation.

## Experimental Validation

The completed closed-loop system was evaluated under three operating conditions:

1. Manual changes in the reference signal.
2. Square-wave reference input.
3. External disturbance applied to the plant.

The system was able to follow changes in the reference while maintaining stable operation and returning to steady state after the introduction of an external disturbance.

### Experimental Performance

| Parameter                 | Experimental Result |
| ------------------------- | ------------------: |
| Maximum overshoot \(M_p\) |              10.25% |
| Dead time \(L\)           |              105 ms |
| 2% settling time \(t_s\)  |              310 ms |

The experimental implementation exhibited differences from the mathematical model due to real-world effects including component tolerances, operational-amplifier limitations, offsets, and additional circuit dynamics.
